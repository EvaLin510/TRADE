# MEXC BTC/USDT 20/100 日均線初步檢驗

更新日期：2026-10-30  
範圍：MEXC BTC/USDT 現貨、約 100 USDT、只做多、不使用槓桿。這是固定規則的探索性歷史比較，不是樣本外驗證或實盤績效。

## 本階段結論

使用 MEXC BTC/USDT 日線資料，固定 20/100 日均線開關，在 2023-04-11 至 2026-10-30 開盤的 1,298 個 open-to-open 區間測試。以單邊 taker 費 5 bps、滑價 5 bps 作基準後：

- 均線策略累積報酬 +55.74%、CAGR 13.27%、年化 Sharpe 0.536、最大回撤 -40.38%、曝險 59.82%、換手 19 次。
- 同期 BTC 買進持有 +162.90%、CAGR 31.23%、Sharpe 0.825、最大回撤 -52.96%、曝險 100%。
- 全程持有 USDT 報酬為 0%。

這條歷史路徑顯示，均線規則最大回撤比 BTC 持有少 12.58 個百分點，但 CAGR 少 17.96 個百分點、Sharpe 也較低。它目前只能定位為回撤管理候選，不能支持「長期打敗 BTC」或「有 alpha」的結論。

## 資料與交易規格

資料取自 MEXC 公開 Spot API 的 BTCUSDT 日線 K 線。抓取範圍自 2023-01-01；本次檢查得到 1,398 根完整日 K，從 2023-01-01 到 2026-10-29，日期連續、無重複或缺日。排除尚未收盤的 2026-10-30 日 K；其 UTC 開盤價作為最後一個可觀察成交標記。

抓取分頁每次實際回傳最多 500 根。MEXC API 的交易對規格快照顯示 BTCUSDT 開放現貨交易及 LIMIT/MARKET 下單，市價單最低名義金額 1 USDT、BTC 數量步進 0.000001 BTC，takerCommission 欄位為 0.0005。100 USDT 高於最低名義金額；該快照不是個人帳戶費率保證，也不模擬下單拒絕或實際成交。

## 回測定義

- 訊號：每根已收盤日 K 計算收盤價的 20 日與 100 日簡單移動平均。20 日均線高於 100 日均線時目標持有 BTC，否則持有 USDT。
- 執行：日 K 收盤後才知道訊號；在下一個 UTC 日開盤執行。策略報酬按開盤到下一個開盤計算，避免用產生訊號的收盤價成交。
- 成本：每次目標曝險變動按換手比例收費。基準 taker 5 bps + 滑價 5 bps，即每單邊 10 bps；另比較 5、15、20 bps/單邊。買進持有初始買入亦扣一次成本；USDT 無交易成本。
- 起始：100 日均線 warm-up 完成後，首個訊號收盤為 2023-04-10，策略於 2023-04-11 開盤開始比較。
- 指標：累積報酬為成本後淨值；CAGR 以實際開盤區間年數年化；Sharpe 使用日報酬、無風險利率 0、年化因子 365；最大回撤由每日淨值高點計算。均為歷史樣本描述統計。

## 限制與決策

1. **沒有獨立 holdout**：固定 20/100 是依前一階段研究選為候選基準；本處涵蓋整段歷史，不是事前封存樣本。結果只能做可行性篩選。下一輪應先鎖定規則，再留出未觸碰區間或做 walk-forward。
2. **單一資產與交易所**：只測 BTCUSDT，不能外推至 ETH、其他幣或其他市場。
3. **成交近似**：用日線開盤價與固定 bps 成本，沒有模擬跳空、部分成交、價差變化、minimum notional 捨入、API 延遲及拒單。
4. **帳戶成本待核對**：MEXC 公開交易對快照的標準 taker 欄位作基準；促銷、地區、帳戶等級及實際交易記錄可能不同。
5. **下一步**：鎖定規則後，先做封存測試及成交粒度／零碎資產模擬；若事前指定 holdout 仍未改善風險調整報酬，不納入部署候選。本階段不連接帳戶或送出訂單。
